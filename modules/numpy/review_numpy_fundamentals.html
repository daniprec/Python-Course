Review: NumPy Fundamentals

Module 3: NumPy

Review of Session 3.1: Fundamentals

Exercise

What is going to be the final value of x?

np = 4

arr = np.array([2, 3, np, 5])

print(arr)

# a) [2, 3, 4, 5]
# b) numpy.ndarray([2, 3, 4, 5])
Solution

Remember that Python will only remember the last variable declaration with the same name. Doing the code above with np is similar to:

x = 10
x = 2
print(x)
2

The code fails because np ceases to be NumPy!

import numpy as np
Exercise

How would you replace the for loop in the code below, for a 1D NumPy array?

arr = np.array([1, 2, 3, 4, 5])

result = 0
for i in arr:
  result = result + i

print(result)
15
arr = np.array([1, 2, 3, 4, 5])

# Option A
result = np.cumsum(arr)

# Option B
result = np.sum(arr)

# Option C
result = np.loop(arr)
AttributeError: module 'numpy' has no attribute 'loop'
Solution

When we do cumsum to a higher dimensional array, NumPy first flattens that array.

arr = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

print(np.cumsum(arr))
[ 1  3  6 10 15 21]
