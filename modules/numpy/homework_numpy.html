Introduction to NumPy

Shadowing the NumPy Alias

Predict what happens when this code runs. Why does np.array() fail?

np = 4
arr = np.array([2, 3, np, 5])
Solution

The assignment np = 4 replaces the NumPy alias with an integer. An integer has no array attribute, so Python raises an AttributeError. Restore the alias before using NumPy again:

import numpy as np
arr = np.array([2, 3, 4, 5])
print(arr)
[2 3 4 5]
Replacing a Sum Loop

for value in arr:
    total = total + value

Choose among np.cumsum(arr), np.sum(arr), and np.loop(arr).

Solution

np.cumsum(arr) returns every running total, while np.sum(arr) returns one value. NumPy has no np.loop() function.

Final Grades with Any Weights

Write a function named final_grades(marks, weights) that receives a 2D array of marks between 0 and 1 (one row per student, one column per exercise) and a 1D array with the points of each exercise. It must return the final grade of each student out of 10, without loops.

Solution 
def final_grades(marks, weights):
    return 10 * (marks @ weights) / np.sum(weights)

Join Daily Recordings

A sensor saves one text file per day, with one value per line. Write a function named join_recordings(filenames) that receives a list of file names, loads each file with np.loadtxt(), and returns a single 1D array with all the values in the order of the list.

def join_recordings(filenames):

    for filename in filenames:

print(np.array_equal(np.load("joined.npy"), joined))  # True

  • cuts: a list with the column indices where each new part starts.

def part_points(marks, weights, cuts):
    mark_parts = np.hsplit(marks, cuts)
    weight_parts = np.split(weights, cuts)

    columns = []
    for m, w in zip(mark_parts, weight_parts):
        columns.append(np.sum(m * w, axis=1))
    return np.column_stack(columns)

Mixed Data Types

Why can this array not be compared directly with the integer 2?

Solution

NumPy chooses one dtype for the complete array. Because strings are present, all values become strings, so comparing them with an integer is invalid. If mixed Python types are required, keep a list and test each element explicitly:

values = ["a", 1, "b", 2, "c", 3, "d", 4]
result = [value for value in values if type(value) is int and value > 2]

[3, 4]

def guess_probability(n_students, n_questions, n_options):

  2. Write encrypt(message, key) that turns the message into an array of positions and encrypts all the letters at once with fancy indexing.
  3. Write decrypt(message, key). Hint: np.argsort(key) gives the inverse permutation.

Sample input:

Expected result: blmmekewmy and helloworld

Solution 
alphabet = np.array(list("abcdefghijklmnopqrstuvwxyz"))


def make_key(seed):
    np.random.seed(seed)
    return np.random.permutation(26)


def to_positions(message):
    return np.array([ord(ch) - ord("a") for ch in message])


def encrypt(message, key):
    return "".join(alphabet[key[to_positions(message)]])


def decrypt(message, key):
    inverse = np.argsort(key)
    return "".join(alphabet[inverse[to_positions(message)]])

print(secret)
print(decrypt(secret, key))
blmmekewmy
helloworld

key[positions] applies the substitution to every letter at once. If key[i] = j, then np.argsort(key)[j] = i, which undoes the substitution.

  2. Compute the candidate c with np.sqrt() and keep only the cells where it is an integer, \(a < b\), and \(c \le n\).
  3. Stack the selected a, b, and c as the three columns of the result.

Sample input: pythagorean_triples(20)
Expected result:

[[ 3  4  5]
 [ 5 12 13]
 [ 6  8 10]
 [ 8 15 17]
 [ 9 12 15]
 [12 16 20]]
Solution 
def pythagorean_triples(n):
    a = np.arange(1, n + 1).reshape(-1, 1)   # column
    b = np.arange(1, n + 1).reshape(1, -1)   # row
    c_squared = a**2 + b**2                  # table (n, n)
    c = np.round(np.sqrt(c_squared)).astype(int)

    mask = (c**2 == c_squared) & (a < b) & (c <= n)
    rows, cols = np.nonzero(mask)
    return np.column_stack((rows + 1, cols + 1, c[mask]))

*Sample input:*


## Solution

```{python}
def part_points(marks, weights, cuts):
    mark_parts = np.hsplit(marks, cuts)
    weight_parts = np.split(weights, cuts)

    columns = []
    for m, w in zip(mark_parts, weight_parts):
        columns.append(np.sum(m * w, axis=1))
    return np.column_stack(columns)


marks = np.array([[1, 0.5, 1, 0, 1], [0.5, 0.5, 0, 1, 1]])
```

In Module 2 you decoded messages with a dictionary of substitution rules. Now build a random substitution cipher with NumPy. Work with lowercase messages without spaces, and represent each letter by its position in the alphabet (`"a"` is 0, `"z"` is 25; `ord(ch) - ord("a")` gives it).

1. Write `make_key(seed)` that fixes the random seed and returns a random permutation of the numbers 0 to 25 (`np.random.permutation()`). The letter at position `i` is encrypted as the letter at position `key[i]`.
2. Write `encrypt(message, key)` that turns the message into an array of positions and encrypts **all the letters at once** with fancy indexing.
3. Write `decrypt(message, key)`. Hint: `np.argsort(key)` gives the inverse permutation.

*Sample input:*

```python
key = make_key(42)

print(secret)

```

*Expected result:* `blmmekewmy` and `helloworld`
:::

::: {.callout-tip collapse="true"}
## Solution

```{python}
alphabet = np.array(list("abcdefghijklmnopqrstuvwxyz"))


def make_key(seed):
    np.random.seed(seed)
    return np.random.permutation(26)


def to_positions(message):
    return np.array([ord(ch) - ord("a") for ch in message])


def encrypt(message, key):
    return "".join(alphabet[key[to_positions(message)]])


def decrypt(message, key):
    inverse = np.argsort(key)
    return "".join(alphabet[inverse[to_positions(message)]])


key = make_key(42)
secret = encrypt("helloworld", key)
print(secret)
print(decrypt(secret, key))
```

`key[positions]` applies the substitution to every letter at once. If `key[i] = j`, then `np.argsort(key)[j] = i`, which undoes the substitution.

```{python}
    correlations = np.zeros(marks.shape[1])
    for j in range(marks.shape[1]):
        correlations[j] = np.corrcoef(marks[:, j], total)[0, 1]
    best = np.argmax(correlations) + 1

    return averages, hardest, best


marks = np.array([
    [1, 0.5, 1, 0],
    [0.5, 0, 1, 1],
    [1, 1, 1, 0],
    [0, 0, 1, 0.5],
    [1, 0.5, 0, 1],
])
print(exercise_report(marks))
```

## Bus Lines, Revisited

In Module 2 you sorted bus lines by how far their route time is from the average time. Do it again with NumPy, without loops. Write `sort_lines(names, times)` that:

2. Sorts the lines by that distance, from closest to farthest.
3. When two lines are equally distant, places the faster one first. Hint: `np.lexsort((times, distances))` sorts by `distances` and breaks ties with `times`.
4. Returns the sorted names and times as two arrays.

*Sample input 1:* `sort_lines(["Line 1", "Line 2", "Line 3"], [50, 30, 40])`  
*Expected result 1:* `['Line 3' 'Line 2' 'Line 1']` and `[40 30 50]`

*Sample input 2:* `sort_lines(["A", "B", "C", "D", "E"], [20, 35, 50, 30, 40])`  
*Expected result 2:* `['B' 'D' 'E' 'A' 'C']` and `[35 30 40 20 50]`
:::

::: {.callout-tip collapse="true"}
## Solution

```{python}
def sort_lines(names, times):
    names = np.array(names)
    times = np.array(times)
    distances = np.abs(times - np.mean(times))

    order = np.lexsort((times, distances))  # last key is the primary key
    return names[order], times[order]


print(sort_lines(["Line 1", "Line 2", "Line 3"], [50, 30, 40]))
print(sort_lines(["A", "B", "C", "D", "E"], [20, 35, 50, 30, 40]))
```

```{python}
def recover_weights(marks, scores):
    return np.linalg.solve(marks, scores)
```

## Vectorize the Grader

The following function computes the final grade of each student, applying a 10% penalty to those who delivered late. Write a function named `grade_vectorized(marks, weights, late)` that returns the same result **without any loop**, where `marks` is a 2D array, `weights` a 1D array, and `late` a Boolean array with one value per student.

```python
def grade_loop(marks, weights, late):
    grades = []
    for i in range(len(marks)):
        total = 0
        for j in range(len(weights)):
            total = total + marks[i][j] * weights[j]
        grade = total / 10
        if late[i]:
            grade = grade * 0.9
        grades.append(round(grade, 2))
    return grades
```

*Sample input:*


Then create random marks for 10,000 students and 11 exercises, check that both functions return the same grades, and compare their running times with `%timeit`.

## Solution

```{python}

    grades = marks @ weights / 10
    grades[late] = grades[late] * 0.9
```

## Pythagorean Triples, Revisited

In Module 1 you checked whether three given numbers form a Pythagorean triple. Now **find all of them** at once, without loops. Write `pythagorean_triples(n)` that returns a 2D array with one row `[a, b, c]` for every triple with $a < b$ and $c \le n$:

1. Build a column of values `a` and a row of values `b`, both from 1 to `n`, and let broadcasting create the table of all $a^2 + b^2$.
2. Compute the candidate `c` with `np.sqrt()` and keep only the cells where it is an integer, $a < b$, and $c \le n$.
3. Stack the selected `a`, `b`, and `c` as the three columns of the result.

*Sample input:* `pythagorean_triples(20)`  
*Expected result:*

```text
[[ 3  4  5]
 [ 5 12 13]
 [ 6  8 10]
 [ 8 15 17]
 [ 9 12 15]
 [12 16 20]]
```
:::

::: {.callout-tip collapse="true"}
## Solution

```{python}
def pythagorean_triples(n):
    a = np.arange(1, n + 1).reshape(-1, 1)   # column
    b = np.arange(1, n + 1).reshape(1, -1)   # row
    c_squared = a**2 + b**2                  # table (n, n)
    c = np.round(np.sqrt(c_squared)).astype(int)

    mask = (c**2 == c_squared) & (a < b) & (c <= n)
    rows, cols = np.nonzero(mask)
    return np.column_stack((rows + 1, cols + 1, c[mask]))


print(pythagorean_triples(20))
```

`np.nonzero(mask)` returns the row and column indices of the `True` cells; adding 1 turns indices into the values of `a` and `b`.
