Module 3: NumPy

Introduction to NumPy

You have just finished the midterm. Now let’s look at it from the other side of the desk: you are the professor, and you have a pile of exams to grade.

The midterm had 11 exercises:

  • Exercises 1 and 2 are open problems, worth 20 points each.
  • Exercises 3 to 5 are debugging exercises, worth 10 points each.
  • Exercises 6 to 11 are multiple-choice questions, worth 5 points each.

To keep things simple, you mark every exercise from 0 (nothing correct) to 1 (fully correct). Later, each mark will be multiplied by the value of its exercise. You store your marks in a table: one row per student, one column per exercise.

Throughout this session, you will manage this table. You will start with the tools you already know, see where they become uncomfortable, and then switch to the right tool for tables of numbers: NumPy.

The Problem: Marks Stored in Lists

Six students took the exam. With what we learned in Module 2, the natural choice is a nested list: one inner list per student.

students = ["Alice", "Bruno", "Chloe", "Diego", "Emma", "Farid"]

marks_list = [
    [0.75, 1, 0.5, 1, 0.5, 1, 1, 0, 1, 1, 1],         # Alice
    [0.5, 0.25, 1, 0.5, 0, 1, 0, 1, 1, 0, 1],         # Bruno
    [1, 1, 1, 1, 0.5, 1, 1, 1, 0, 1, 1],              # Chloe
    [0.25, 0.5, 0, 0.5, 0.5, 0, 1, 0, 1, 0, 1],       # Diego
    [1, 0.75, 0.5, 1, 1, 1, 0, 1, 1, 1, 1],           # Emma
    [0.5, 0.5, 0.5, 0, 1, 1, 1, 0, 0, 1, 0],          # Farid
]

Some questions are easy. All the marks of Alice are one row:

print(marks_list[0])
[0.75, 1, 0.5, 1, 0.5, 1, 1, 0, 1, 1, 1]

Other questions are not. To check how the class did in exercise 4, we need to visit every row and take its fourth element:

exercise_4 = [row[3] for row in marks_list]
print(exercise_4)
[1, 0.5, 1, 0.5, 1, 0]

And to review the open problems (exercises 1 and 2) of Bruno, Chloe, and Diego, we combine a slice of rows with a slice inside every row:

block = [row[:2] for row in marks_list[1:4]]
print(block)
[[0.5, 0.25], [1, 1], [0.25, 0.5]]
Exercise: The Last Question

Using only lists, get the marks of exercise 11 (the last one) for the last three students.

Solution 
last_question = [row[-1] for row in marks_list[-3:]]
print(last_question)
[1, 1, 0]

This works, but every new question needs a new loop or comprehension, and the code no longer looks like the question we asked. A list does not know that it is a table: it only knows that it contains other lists. We need a tool that understands rows and columns.

What is NumPy?

NumPy (Numerical Python) is a package for numerical computing. It provides multidimensional arrays and mathematical functions designed to operate on those arrays efficiently. By the end of this session, the two questions above will be one short expression each. By the end of the next session, computing the final grade of every student will be one line too.

Why Use NumPy?

  • Arrays store numerical data efficiently.
  • Arrays know their own shape: rows, columns, and beyond.
  • Array operations usually require less code than equivalent list-based loops.
  • NumPy’s optimized implementation makes large calculations fast.
# First, let's import NumPy
import numpy as np
ModuleNotFoundError: No module named 'numpy'

Creating Arrays

To create an array we use the function np.array(). We must pass a list or tuple to the function. Let’s start with the value of each exercise, in points.

weights = np.array([20, 20, 10, 10, 10, 5, 5, 5, 5, 5, 5])
print(weights)
NameError: name 'np' is not defined

Tuples work too. Imagine that the marks of one student arrive as a tuple from another program:

alice = np.array((0.75, 1, 0.5, 1, 0.5, 1, 1, 0, 1, 1, 1))
print(alice)
NameError: name 'np' is not defined
What about sets?

Suppose the student IDs of the group are stored in a set: {101, 102, 103}. The np.array documentation says that the object must be an array or “any (nested) sequence”. A set is not a sequence: it is unordered and does not support indexing. NumPy therefore stores the whole set as one single Python object, not as three IDs.

ids = np.array({101, 102, 103})

print(ids)
print(ids.shape)
print(ids.dtype)
NameError: name 'np' is not defined

Convert the set to a list first: np.array(sorted({101, 102, 103})).

Exercise: Three Arguments

You try to store Diego’s debugging marks. Without running the code, decide what happens.

diego_debugging = np.array(0, 0.5, 0.5)

print(diego_debugging)
Solution

The code raises a TypeError. np.array() expects one object (a list or tuple) as its first argument, but here it receives three separate values. The fix is np.array([0, 0.5, 0.5]).

Array Types

Look again at Alice’s marks: we typed 1 and 0 as integers, but NumPy printed 1. and 0.. Every NumPy array has one data type, available through its dtype property. When the input mixes types, NumPy chooses one type capable of representing every value.

print(alice.dtype)
print(weights.dtype)
NameError: name 'alice' is not defined
Exercise: Mixed Marks

The multiple-choice questions are marked 0 or 1, while the debugging exercises can get 0.5. Without running the code, write down what each line prints.

chloe_mc = np.array([1, 1, 1, 0, 1, 1])
chloe_debugging = np.array([1, 1, 0.5])

print(chloe_mc, chloe_mc.dtype)
print(chloe_debugging, chloe_debugging.dtype)
Solution 
[1 1 1 0 1 1] int64
[1.  1.  0.5] float64

The first array only contains integers, so it keeps an integer type. In the second, a single 0.5 is enough to turn every element into a float, so the array has one data type. (On some Windows installations the integer type may show as int32.)

This rule has a consequence. Why don’t we store the student names inside the table, as the first column?

row = np.array(["Alice", 0.75, 1, 0.5])

print(row)
print(row.dtype)
NameError: name 'np' is not defined

The only type that can represent both "Alice" and 0.75 is a string, so every mark became text. That is why we keep students in a separate list, and only numbers in the array.

Exercise: The Unreadable Answer

While grading Farid’s exam, you cannot read his answer to exercise 2, so you type "?" until you ask him. Without running the code, what is the dtype of farid? Why is it a problem?

farid = np.array([0.5, "?", 0.5, 0])

print(farid.dtype)
Solution

The array becomes an array of strings (its dtype is <U32, a Unicode string). Every mark is now text, so we can no longer treat the row as numbers.

NumPy has a special float value for missing data, np.nan (“not a number”), which keeps the array numeric:

farid = np.array([0.5, np.nan, 0.5, 0])
print(farid)
print(farid.dtype)
NameError: name 'np' is not defined

We can also choose the type ourselves, in the second argument of np.array(). If a value cannot be converted, NumPy raises an error instead of silently changing the type.

a = np.array([1, 0, 1], float)
print(a)
NameError: name 'np' is not defined
a = np.array([1, "?", 1], float)
NameError: name 'np' is not defined

Multi-Dimensional Arrays

One student is a one-dimensional array. The whole group is a two-dimensional array, created from the nested list.

marks = np.array(marks_list)
print(marks)
NameError: name 'np' is not defined

Compare this output with print(marks_list): NumPy prints the table as a table, with aligned rows and columns.

In NumPy, the order of dimensions is indicated by the nesting of brackets. The outermost brackets represent the first dimension (dimension 0, the rows, here the students). The next level of brackets represents the second dimension (dimension 1, the columns, here the exercises). Each new level of nesting adds one more dimension.

A table must be rectangular: every row needs the same number of values. What if you forget to type one of Diego’s marks?

broken = np.array([
    [0.75, 1, 0.5, 1, 0.5, 1, 1, 0, 1, 1, 1],
    [0.25, 0.5, 0, 0.5, 0.5, 0, 1, 0, 1, 0],    # Diego: only 10 marks
])
NameError: name 'np' is not defined
Exercise: Two Campuses

The same exam was taken in two campuses, Madrid and Segovia. Create a single array called campuses that stores, for each campus, the marks of two students in the two open problems. Use these marks:

  • Madrid: student 1 got 0.75, 1 and student 2 got 0.5, 0.25.
  • Segovia: student 1 got 1, 0.5 and student 2 got 0.25, 0.75.

How many levels of brackets do you need?

Solution 
campuses = np.array([
    [[0.75, 1], [0.5, 0.25]],   # Madrid
    [[1, 0.5], [0.25, 0.75]],   # Segovia
])
print(campuses)
NameError: name 'np' is not defined

We need three levels of brackets, so the array is three-dimensional: campuses, then students, then exercises.

Basic Properties of Arrays

An array knows its own structure. Unlike methods, properties don’t require parentheses when accessed. Here are four key properties, applied to our table of marks.

ndim: the number of dimensions of the array.

print(marks.ndim)
NameError: name 'marks' is not defined

shape: a tuple with the length of each dimension. For a table with n rows and m columns, the shape is (n, m): here, 6 students and 11 exercises.

print(marks.shape)
NameError: name 'marks' is not defined

size: the total number of elements, here the total number of marks you wrote.

print(marks.size)
NameError: name 'marks' is not defined

dtype: the data type of the elements.

print(marks.dtype)
NameError: name 'marks' is not defined
Exercise: Shapes That Must Agree
  1. Print the shape of weights. Which number of marks.shape must it match, and why?
  2. A seventh student takes the exam late, and you add a bonus exercise 12 for everyone. Without running any code, predict the ndim, shape, and size of the new table of marks.
  3. Predict the same three properties for campuses.
Solution
  1. weights.shape is (11,): one value per exercise. It must match the number of columns of marks, marks.shape[1], because every column is one exercise.
  2. The new table has ndim 2, shape (7, 12), and size 84.
  3. For campuses:
print(weights.shape, marks.shape[1])
print(campuses.ndim, campuses.shape, campuses.size)
NameError: name 'weights' is not defined

Creating Arrays Without Typing Them

Typing every value is fine for six students, but the other group has 30. NumPy can build arrays of any shape for us.

np.zeros() creates an array full of zeros. It is an empty table of marks for 30 students and 11 exercises, waiting to be filled. Note that the shape is passed as one tuple.

new_group = np.zeros((30, 11))
print(new_group.shape)
NameError: name 'np' is not defined

np.ones() works the same way. What does a perfect exam look like?

perfect = np.ones(11)
print(perfect)
NameError: name 'np' is not defined

np.arange(start, stop, step) works like range(), but returns an array. The exercise numbers go from 1 to 11:

exercise_numbers = np.arange(1, 12)
print(exercise_numbers)
NameError: name 'np' is not defined

np.linspace(start, stop, num) returns num values evenly spaced between start and stop, both included. It is perfect to build a marking rubric. The open problems are marked in quarters:

open_rubric = np.linspace(0, 1, 5)
print(open_rubric)
NameError: name 'np' is not defined
Exercise: Exam Versions

To avoid copying, students in odd seats (1, 3, 5, …) get version A of the exam. The room has 30 seats. Create an array with the seat numbers that get version A.

Solution 
version_a = np.arange(1, 31, 2)
print(version_a)
NameError: name 'np' is not defined
Exercise: The Debugging Rubric

The debugging exercises are marked in halves: no error found, one error found, or both errors found.

  1. Create this rubric with np.linspace().
  2. Create the rubric of the open problems again, but now with np.arange(). Be careful with the stopping value!
Solution 
debugging_rubric = np.linspace(0, 1, 3)
print(debugging_rubric)

open_rubric = np.arange(0, 1.25, 0.25)
print(open_rubric)
NameError: name 'np' is not defined

np.arange() excludes its stopping value, so we must stop one step after 1. np.linspace() includes both ends and asks for the number of values instead of the step, which is usually easier for rubrics.

Reshape: From a Form to a Table

Imagine that you graded the exams in an online form, which exports all the marks as one long list: first the 11 marks of the first student, then the 11 marks of the second, and so on.

form_export = np.array([
    0.75, 1, 0.5, 1, 0.5, 1, 1, 0, 1, 1, 1,
    0.5, 0.25, 1, 0.5, 0, 1, 0, 1, 1, 0, 1,
    1, 1, 1, 1, 0.5, 1, 1, 1, 0, 1, 1,
    0.25, 0.5, 0, 0.5, 0.5, 0, 1, 0, 1, 0, 1,
    1, 0.75, 0.5, 1, 1, 1, 0, 1, 1, 1, 1,
    0.5, 0.5, 0.5, 0, 1, 1, 1, 0, 0, 1, 0,
])
print(form_export.shape)
NameError: name 'np' is not defined

The reshape() method reorganizes the same values into a new shape, row by row. It returns a new array and does not modify the original.

table = form_export.reshape(6, 11)
print(table)
NameError: name 'form_export' is not defined

The requested shape must contain exactly the same number of elements as the original array.

table = form_export.reshape(6, 10)
NameError: name 'form_export' is not defined
Exercise: Grading Exercise by Exercise

Many professors grade exercise by exercise: first exercise 1 for every student, then exercise 2 for every student, and so on. A form filled in that order exports the 6 marks of exercise 1, then the 6 marks of exercise 2, and so on. Which reshape() gives a table with the right structure? What is its shape, and what does each row represent?

Solution

.reshape(11, 6), which gives a table with shape (11, 6): one row per exercise and one column per student. Reshape fills the new array row by row, so the reshape must follow the order in which the values arrive. Turning this table into one row per student is a different operation (transposing), which we will see in a later session.

Array Indexing: One Mark

Indexing a one-dimensional array is the same as indexing lists, tuples, or strings. Be careful: exercise 1 is at index 0.

print(weights[0])  # value of exercise 1
print(alice[3])      # Alice's mark in exercise 4
NameError: name 'weights' is not defined

Indexing a two-dimensional array with one index returns a whole row: one student.

print(marks[2])  # Chloe
NameError: name 'marks' is not defined

Indexing it “like a nested list” works too: first the row, then the element inside that row.

print(marks[2][4])  # Chloe, exercise 5
NameError: name 'marks' is not defined

For NumPy arrays, we can include all indices within a single pair of brackets, separated by commas. This is called indexing with a tuple, and it reads as marks[student, exercise].

print(marks[2, 4])  # Chloe, exercise 5
NameError: name 'marks' is not defined

We do not need to remember the position of every student. The list method index() from Module 2 finds it for us:

row = students.index("Diego")

print(marks[row, 0])  # Diego, exercise 1
NameError: name 'marks' is not defined

Indexing also lets us change a value. Diego asked for a revision of exercise 3, and you realize he found one of the two errors. His mark goes up to 0.5:

marks[3, 2] = 0.5
print(marks[3])
NameError: name 'marks' is not defined
Exercise: Negative Row Index

Without running the code, write down what it prints.

print(marks[-1, 0])
Solution 
0.5

-1 selects the last row (Farid) and 0 selects exercise 1.

Exercise: Lists Are Not Arrays

What happens when this code runs? Explain why.

print(marks_list[2, 4])
Solution

The code raises TypeError: list indices must be integers or slices, not tuple. marks_list is a nested list, and lists cannot be indexed with a tuple. Use marks_list[2][4] for the list, or marks[2, 4] for the array.

Exercise: Two Versions

The exam had two versions, and you keep the marks of each version in its own array (three exercises shown). Without running the code, find the value of x.

version_A = np.array([[1, 0.5, 0], [0.25, 1, 1]])
version_B = np.array([[0.75, 0, 1], [1, 0.5, 0.5]])

versions = [version_A, version_B]

x = versions[1][0, 2]

print(x)
Solution 
1.0

versions[1] is a list index that returns version_B. Then [0, 2] is an array index: first student, third exercise. The array contains floats, so the value prints as 1.0.

Emma also asked for a revision. Her open problem in exercise 2 deserves full marks. Update the table using students.index() and the exercise number, then print Emma’s row.

Array Slicing: Rows, Columns, and Blocks

Slicing a one-dimensional array is the same as slicing a list. The start is included and the stop is excluded. The three parts of the exam are three slices:

print(weights[:2])    # open problems
print(weights[2:5])   # debugging
print(weights[5:])    # multiple choice
NameError: name 'weights' is not defined

With a two-dimensional array, we can slice each dimension separately, inside the same brackets. A colon : alone means “everything along this dimension”. This solves the first question of the session, how the class did in exercise 4, in one expression:

print(marks[:, 3])  # all students, exercise 4
NameError: name 'marks' is not defined

And the whole exam of one student:

print(marks[1, :])  # Bruno, all exercises
NameError: name 'marks' is not defined

The second question of the session, the open problems of Bruno, Chloe, and Diego, is a block of rows and columns:

print(marks[1:4, :2])
NameError: name 'marks' is not defined

Compare it with the list version, [row[:2] for row in marks_list[1:4]]. The NumPy version reads exactly like the question: rows 1 to 3, columns 0 to 1.

Steps work as they do in lists. If students sat in alternating seats, every other row starting from the first one got version A:

print(marks[::2])
NameError: name 'marks' is not defined

A negative step reverses the order. When you collect the exams, the last one delivered ends up on top of the pile:

print(marks[::-1])
NameError: name 'marks' is not defined

Slices can also be used to fill an array. Suppose a machine grades the multiple-choice part automatically, and sends you the six marks of each student at once:

small_group = np.zeros((3, 11))

small_group[0] = [1, 0.5, 1, 0.5, 1, 1, 0, 1, 1, 1, 1]   # first student, typed by hand
small_group[1:, 5:] = [
    [1, 1, 0, 1, 1, 0],    # second student, multiple choice
    [0, 1, 1, 1, 0, 1],    # third student, multiple choice
]

print(small_group)
NameError: name 'np' is not defined
Exercise: Version B

Students in even seats (Bruno, Diego, and Farid) got version B. Use one slice to get all their marks.

Solution 
print(marks[1::2])
NameError: name 'marks' is not defined

Get the marks of the debugging part (exercises 3 to 5) for every student, and the value of those exercises.

Get the marks of exercise 1 for Farid, Emma, and Diego, in that order.

Extra: An Image Is Also a Table

A table of marks is a table of numbers. What else could be stored as a table of numbers? A picture.

A digital image is a grid of small squares called pixels. In a grayscale image, each pixel is one number: 0 is black, 1 is white, and the values in between are shades of gray. So an image is just a two-dimensional array, where the shape is (height, width).

The helper function below displays an array as an image. You do not need to understand how it works: we will learn more about plotting later in the course.

import matplotlib.pyplot as plt


def show(image):
    """Display a 2D array as a grayscale image (0 = black, 1 = white)."""
    plt.imshow(image, cmap="gray", vmin=0, vmax=1)
    plt.axis("off")
    plt.show()
ModuleNotFoundError: No module named 'matplotlib'

Everything we learned today works on images. A black canvas is np.zeros(), and we paint with indexing and slicing:

face = np.zeros((8, 8))

face[2, 2] = 1        # left eye
face[2, 5] = 1        # right eye
face[5, 2:6] = 1      # mouth
face[4, 1] = 1        # left corner of the smile
face[4, 6] = 1        # right corner of the smile

show(face)
NameError: name 'np' is not defined
Exercise: Upside Down

Without changing face, display it upside down. Then display its mirror image (left and right swapped).

Solution 
show(face[::-1])     # reverse the rows
show(face[:, ::-1])  # reverse the columns
NameError: name 'show' is not defined
Exercise: A Chessboard

Create an \(8 \times 8\) chessboard (alternating black and white squares) using np.zeros() and only two slice assignments.

Solution 
board = np.zeros((8, 8))

board[::2, 1::2] = 1   # even rows, odd columns
board[1::2, ::2] = 1   # odd rows, even columns

show(board)
NameError: name 'np' is not defined

With lists, this needs two nested loops and a condition. With slicing, each line paints a whole set of squares.

Color images add a third dimension: each pixel stores three numbers (red, green, and blue), so their shape is (height, width, 3). We will come back to images later in this module.

Summary and Reflection

  • A NumPy array is a table of values of one data type; mixing types changes the dtype of every element.
  • ndim, shape, size, and dtype describe an array.
  • np.zeros(), np.ones(), np.arange(), and np.linspace() build arrays without typing the values; reshape() reorganizes them.
  • marks[row, col] selects one value; slices such as marks[:, 3] or marks[1:4, :2] select rows, columns, and blocks.
  • Slice stopping positions are excluded, just as they are for lists.

# Introduction to NumPy

You have just finished the midterm. Now let's look at it from the other side of the desk: **you are the professor**, and you have a pile of exams to grade.

The midterm had 11 exercises:

- Exercises 1 and 2 are open problems, worth **20 points** each.
- Exercises 3 to 5 are debugging exercises, worth **10 points** each.
- Exercises 6 to 11 are multiple-choice questions, worth **5 points** each.

To keep things simple, you mark every exercise from `0` (nothing correct) to `1` (fully correct). Later, each mark will be multiplied by the value of its exercise. You store your marks in a table: **one row per student, one column per exercise**.

Throughout this session, you will manage this table. You will start with the tools you already know, see where they become uncomfortable, and then switch to the right tool for tables of numbers: **NumPy**.

## The Problem: Marks Stored in Lists

Six students took the exam. With what we learned in Module 2, the natural choice is a nested list: one inner list per student.

```{python}

    [0.5, 0.5, 0.5, 0, 1, 1, 1, 0, 0, 1, 0],          # Farid
```

```{python}
exercise_4 = [row[3] for row in marks_list]
```

## What is NumPy?

NumPy (Numerical Python) is a package for numerical computing. It provides multidimensional arrays and mathematical functions designed to operate on those arrays efficiently. By the end of this session, the two questions above will be one short expression each. By the end of the next session, computing the final grade of every student will be one line too.

### Why Use NumPy?

- Arrays store numerical data efficiently.
- Arrays know their own shape: rows, columns, and beyond.
- Array operations usually require less code than equivalent list-based loops.
- NumPy's optimized implementation makes large calculations fast.

```{python}
# First, let's import NumPy
import numpy as np
```

## Creating Arrays

To create an array we use the function `np.array()`. We must pass a list or tuple to the function. Let's start with the value of each exercise, in points.

```{python}
weights = np.array([20, 20, 10, 10, 10, 5, 5, 5, 5, 5, 5])
print(weights)
```

Tuples work too. Imagine that the marks of one student arrive as a tuple from another program:

```{python}
alice = np.array((0.75, 1, 0.5, 1, 0.5, 1, 1, 0, 1, 1, 1))
print(alice)
```

::: {.callout-warning}
## What about sets?

Suppose the student IDs of the group are stored in a set: `{101, 102, 103}`. The [np.array documentation](https://numpy.org/doc/stable/reference/generated/numpy.array.html) says that the object must be an array or "any (nested) sequence". A set is not a [sequence](https://docs.python.org/3/glossary.html#term-sequence): it is unordered and does not support indexing. NumPy therefore stores the whole set as one single Python object, not as three IDs.

```{python}
ids = np.array({101, 102, 103})

print(ids)
print(ids.shape)
print(ids.dtype)
```

Convert the set to a list first: `np.array(sorted({101, 102, 103}))`.

### Array Types

Look again at Alice's marks: we typed `1` and `0` as integers, but NumPy printed `1.` and `0.`. Every NumPy array has **one** data type, available through its `dtype` property. When the input mixes types, NumPy chooses one type capable of representing every value.

```{python}
print(alice.dtype)
print(weights.dtype)
```

::: {.callout-note}

The first array only contains integers, so it keeps an integer type. In the second, a single `0.5` is enough to turn every element into a float, so the array has one data type. (On some Windows installations the integer type may show as `int32`.)

This rule has a consequence. Why don't we store the student names inside the table, as the first column?

```{python}

```

The only type that can represent both `"Alice"` and `0.75` is a string, so **every mark became text**. That is why we keep `students` in a separate list, and only numbers in the array.

### Multi-Dimensional Arrays

One student is a one-dimensional array. The whole group is a **two-dimensional** array, created from the nested list.

```{python}
marks = np.array(marks_list)
print(marks)
```

Compare this output with `print(marks_list)`: NumPy prints the table as a table, with aligned rows and columns.

In NumPy, the order of dimensions is indicated by the nesting of brackets. The outermost brackets represent the first dimension (dimension 0, the **rows**, here the students). The next level of brackets represents the second dimension (dimension 1, the **columns**, here the exercises). Each new level of nesting adds one more dimension.

A table must be rectangular: every row needs the same number of values. What if you forget to type one of Diego's marks?

```{python}
broken = np.array([
    [0.75, 1, 0.5, 1, 0.5, 1, 1, 0, 1, 1, 1],
    [0.25, 0.5, 0, 0.5, 0.5, 0, 1, 0, 1, 0],    # Diego: only 10 marks
])
```

```{python}
print(marks.shape)
```

`size`: the total number of elements, here the total number of marks you wrote.

```{python}
print(marks.size)
```

`dtype`: the data type of the elements.

```{python}
new_group = np.zeros((30, 11))
```

```{python}
open_rubric = np.linspace(0, 1, 5)
```

### Reshape: From a Form to a Table

Imagine that you graded the exams in an online form, which exports all the marks as one long list: first the 11 marks of the first student, then the 11 marks of the second, and so on.

```{python}
form_export = np.array([
    0.75, 1, 0.5, 1, 0.5, 1, 1, 0, 1, 1, 1,
    0.5, 0.25, 1, 0.5, 0, 1, 0, 1, 1, 0, 1,
    1, 1, 1, 1, 0.5, 1, 1, 1, 0, 1, 1,
    0.25, 0.5, 0, 0.5, 0.5, 0, 1, 0, 1, 0, 1,
    1, 0.75, 0.5, 1, 1, 1, 0, 1, 1, 1, 1,
    0.5, 0.5, 0.5, 0, 1, 1, 1, 0, 0, 1, 0,
])
print(form_export.shape)
```

The `reshape()` method reorganizes the same values into a new shape, row by row. It returns a new array and does not modify the original.

```{python}
table = form_export.reshape(6, 11)
print(table)
```

The requested shape must contain exactly the same number of elements as the original array.

```{python}
table = form_export.reshape(6, 10)
```

## Array Indexing: One Mark

Indexing a one-dimensional array is the same as indexing lists, tuples, or strings. Be careful: exercise 1 is at index `0`.

```{python}
print(weights[0])  # value of exercise 1
print(alice[3])      # Alice's mark in exercise 4
```

Indexing a two-dimensional array with one index returns a whole row: one student.

```{python}
print(marks[2])  # Chloe
```

Indexing it "like a nested list" works too: first the row, then the element inside that row.

```{python}
print(marks[2][4])  # Chloe, exercise 5
```

For NumPy arrays, we can include all indices within a single pair of brackets, separated by commas. This is called **indexing with a tuple**, and it reads as `marks[student, exercise]`.

```{python}
print(marks[2, 4])  # Chloe, exercise 5
```

We do not need to remember the position of every student. The list method `index()` from Module 2 finds it for us:

```{python}
row = students.index("Diego")

print(marks[row, 0])  # Diego, exercise 1
```

Indexing also lets us **change** a value. Diego asked for a revision of exercise 3, and you realize he found one of the two errors. His mark goes up to `0.5`:

```{python}
marks[3, 2] = 0.5
print(marks[3])
```

## Array Slicing: Rows, Columns, and Blocks

Slicing a one-dimensional array is the same as slicing a list. The start is included and the stop is excluded. The three parts of the exam are three slices:

```{python}
print(weights[:2])    # open problems
print(weights[2:5])   # debugging
print(weights[5:])    # multiple choice
```

With a two-dimensional array, we can slice **each dimension separately**, inside the same brackets. A colon `:` alone means "everything along this dimension". This solves the first question of the session, how the class did in exercise 4, in one expression:

```{python}
print(marks[:, 3])  # all students, exercise 4
```

And the whole exam of one student:

```{python}
print(marks[1, :])  # Bruno, all exercises
```

The second question of the session, the open problems of Bruno, Chloe, and Diego, is a block of rows and columns:

```{python}
print(marks[1:4, :2])
```

Compare it with the list version, `[row[:2] for row in marks_list[1:4]]`. The NumPy version reads exactly like the question: rows 1 to 3, columns 0 to 1.

Steps work as they do in lists. If students sat in alternating seats, every other row starting from the first one got version A:

```{python}
print(marks[::2])
```

A negative step reverses the order. When you collect the exams, the last one delivered ends up on top of the pile:

```{python}
print(marks[::-1])
```

Slices can also be used to **fill** an array. Suppose a machine grades the multiple-choice part automatically, and sends you the six marks of each student at once:

```{python}
small_group = np.zeros((3, 11))

small_group[0] = [1, 0.5, 1, 0.5, 1, 1, 0, 1, 1, 1, 1]   # first student, typed by hand
small_group[1:, 5:] = [
    [1, 1, 0, 1, 1, 0],    # second student, multiple choice
    [0, 1, 1, 1, 0, 1],    # third student, multiple choice
]

print(small_group)
```

## Extra: An Image Is Also a Table

A table of marks is a table of numbers. What else could be stored as a table of numbers? A **picture**.

A digital image is a grid of small squares called **pixels**. In a grayscale image, each pixel is one number: `0` is black, `1` is white, and the values in between are shades of gray. So an image is just a two-dimensional array, where the shape is `(height, width)`.

The helper function below displays an array as an image. You do not need to understand how it works: we will learn more about plotting later in the course.

```{python}
import matplotlib.pyplot as plt


def show(image):
    """Display a 2D array as a grayscale image (0 = black, 1 = white)."""
    plt.imshow(image, cmap="gray", vmin=0, vmax=1)
    plt.axis("off")
    plt.show()
```

Everything we learned today works on images. A black canvas is `np.zeros()`, and we paint with indexing and slicing:

```{python}
face = np.zeros((8, 8))

face[2, 2] = 1        # left eye
face[2, 5] = 1        # right eye
face[5, 2:6] = 1      # mouth
face[4, 1] = 1        # left corner of the smile
face[4, 6] = 1        # right corner of the smile

show(face)
```

::: {.callout-note}
## Exercise: Upside Down

Without changing `face`, display it upside down. Then display its mirror image (left and right swapped).
:::

::: {.callout-tip collapse="true"}
## Solution

```{python}
show(face[::-1])     # reverse the rows
show(face[:, ::-1])  # reverse the columns
```
:::

::: {.callout-note}
## Exercise: A Chessboard

Create an $8 \times 8$ chessboard (alternating black and white squares) using `np.zeros()` and **only two** slice assignments.
:::

::: {.callout-tip collapse="true"}
## Solution

```{python}
board = np.zeros((8, 8))

board[::2, 1::2] = 1   # even rows, odd columns
board[1::2, ::2] = 1   # odd rows, even columns

show(board)
```

With lists, this needs two nested loops and a condition. With slicing, each line paints a whole set of squares.
:::

## Summary and Reflection

- A NumPy array is a table of values of **one** data type; mixing types changes the `dtype` of every element.
- `ndim`, `shape`, `size`, and `dtype` describe an array.
- `np.zeros()`, `np.ones()`, `np.arange()`, and `np.linspace()` build arrays without typing the values; `reshape()` reorganizes them.
- `marks[row, col]` selects one value; slices such as `marks[:, 3]` or `marks[1:4, :2]` select rows, columns, and blocks.
- Slice stopping positions are excluded, just as they are for lists.
