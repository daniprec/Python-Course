        yield current
        current += step

*Sample usage:* `[time for time in clock(4)]`  
*Expected result:* `["00:00:00", "00:00:01", "00:00:02", "00:00:03"]`

::: {.callout-tip collapse="true"}
## Solution

```{python}
#| eval: false
def clock(limit):
    hour, minute, second = 0, 0, 0
    for _ in range(limit):
        yield f"{hour:02d}:{minute:02d}:{second:02d}"
        second += 1
        if second == 60:
            second = 0
            minute += 1
            if minute == 60:
                minute = 0
                hour += 1
                if hour == 24:
                    hour = 0

print([time for time in clock(4)])
```

## Prime Number Generator

Create a generator function `prime_numbers(num)` that yields prime numbers within a specified range.

*Sample input:* `[number for number in prime_numbers(9)]`  
*Expected result:* `[2, 3, 5, 7]`

::: {.callout-tip collapse="true"}
## Solution

```{python}
#| eval: false
def prime_numbers(num):
    def is_prime(n):
        if n < 2:
            return False
        for i in range(2, int(n**0.5) + 1):
            if n % i == 0:
                return False
        return True
    
    for i in range(2, num):
        if is_prime(i):
            yield i

print([number for number in prime_numbers(9)])
```
