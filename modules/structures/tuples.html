Tuples

Data Structures: Tuples

A tuple stores an ordered collection of items. Tuples are similar to lists, but they cannot be changed after creation.

This makes them useful for information that should remain fixed, such as the days of the week, a booking record, or the details returned by a function.

Creating Tuples

Create a tuple by separating items with commas. Parentheses () make the structure easier to read and are normally included.

languages = ("Python", "JavaScript", "R")

print(languages)
('Python', 'JavaScript', 'R')
print(type(languages))
<class 'tuple'>

Compare the syntax for a list and a tuple:

fruit_list = ["apple", "banana", "cherry"]

print(type(fruit_list))
<class 'list'>
fruit_tuple = ("apple", "banana", "cherry")

print(type(fruit_tuple))
<class 'tuple'>

One-item Tuples

A one-item tuple needs a trailing comma. Without the comma, Python treats the parentheses as ordinary grouping.

not_a_tuple = ("Python")
one_item_tuple = ("Python",)

print(type(not_a_tuple))
print(type(one_item_tuple))
<class 'str'>
<class 'tuple'>
Exercise: Spot the tuple

Before running the code, decide which variables contain tuples.

b = ("weekend",)
c = "weekend",
d = ["weekend"]
Solution

b and c are tuples. The comma creates the tuple; parentheses are optional in many situations.

Properties of Tuples

Ordered

Tuples preserve the order of their items. Like lists, they use zero-based indexing and support negative indexes.

weekdays = ("Monday", "Tuesday", "Wednesday", "Thursday", "Friday")

print(weekdays[0])
Monday
print(weekdays[-1])
Friday

Tuples also support slicing.

print(weekdays[1:4])
('Tuesday', 'Wednesday', 'Thursday')
print(weekdays[:2])
('Monday', 'Tuesday')

Duplicate Items

Tuples can contain the same value more than once.

survey_answers = ("yes", "no", "yes", "maybe", "yes")

print(survey_answers)
('yes', 'no', 'yes', 'maybe', 'yes')

Immutable

Tuples are immutable. Their items cannot be replaced, added, or removed after the tuple is created.

weekdays = ("Monday", "Tuesday", "Wednesday", "Thursday", "Friday")
weekdays[0] = "Sunday"
TypeError: 'tuple' object does not support item assignment

Immutability protects information from accidental changes. It also means that methods such as append(), remove(), and sort() are not available for tuples.

Tuple Operations

The + operator combines tuples, and * repeats them.

morning = ("coffee", "email")
afternoon = ("class", "study")

day_plan = morning + afternoon
print(day_plan)

reminders = ("stand up",) * 3
print(reminders)
('coffee', 'email', 'class', 'study')
('stand up', 'stand up', 'stand up')

The len() function returns the number of items.

print(len(day_plan))
4

The in operator checks whether an item is present.

print("class" in day_plan)
True
print("gym" in day_plan)
False

Tuple Methods

Because tuples are immutable, they have only two commonly used methods:

  • count() returns the number of times a value appears.
  • index() returns the index of the first matching value.
survey_answers = ("yes", "no", "yes", "maybe", "yes")

print(survey_answers.count("yes"))
3
print(survey_answers.index("maybe"))
3

Packing and Unpacking

Creating a tuple is sometimes called packing because several values are packed into one object.

booking = ("Aisha Khan", "Madrid", "18:45")

print(booking)
('Aisha Khan', 'Madrid', '18:45')

Unpacking assigns each item to a separate variable.

passenger, destination, departure_time = booking

print(passenger)
print(destination)
print(departure_time)
Aisha Khan
Madrid
18:45

The number of variables must match the number of tuple items.

Converting Between Lists and Tuples

Use list() when a tuple needs to be changed. After editing it, use tuple() to convert it back.

route = ("Lisbon", "Paris", "Berlin")

editable_route = list(route)
editable_route.append("Prague")
route = tuple(editable_route)

print(route)
('Lisbon', 'Paris', 'Berlin', 'Prague')

Returning Multiple Values

A function can return several values as a tuple.

def describe_title(title):
    cleaned_title = title.strip().title()
    character_count = len(cleaned_title)
    return cleaned_title, character_count


book_title, title_length = describe_title("  the left hand of darkness  ")

print(book_title)
print(title_length)
The Left Hand Of Darkness
25

Write a function named event_summary() that receives an event name and a city. It should return both values with title case applied. Unpack the result and print it.

## Summary

- Tuples usually use parentheses: `()`.

- Functions can return multiple values in a tuple.
