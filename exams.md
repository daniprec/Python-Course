This page contains quizzes and exams from previous years. Use them to practise, review the main concepts, and understand the expected level of difficulty.

Exam formats and assessment criteria have changed over time, so older materials may not match the current structure exactly. However, the core concepts remain relevant.

Some exams include solutions. For those that do not, you may use an AI assistant to draft a solution, but make sure you check its reasoning and code carefully.

If you have any questions, contact me at [dprecioso@faculty.ie.edu](mailto:dprecioso@faculty.ie.edu).

## Assessment coverage

| Assessment             | Modules covered                                   |
| ---------------------- | ------------------------------------------------- |
| Quizzes                | Module 1: Fundamentals; Module 3: NumPy           |
| Midterm exam           | Module 1: Fundamentals; Module 2: Data Structures |
| Final and retake exams | Modules 1 to 3                                    |

Module 2 has no separate quizzes because it is assessed in the midterm exam. Module 4 focuses on development tools and IDEs, so it is not assessed.
